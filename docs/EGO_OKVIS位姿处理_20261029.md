输出：data/ego_pose_h5/<会话名>_ego_pose.h5。pose/下保存timestamp_ns（原EGO单调时钟）、pc_timestamp_ns（既有时钟模型映射）、clock_extrapolated、position、quaternion_xyzw、velocity_world_m_s、gyro_bias_rad_s、accel_bias_m_s2、tracking_quality、tracking_good。质量按完全相同时间戳匹配最新回调，未匹配为-1；不做插值。

位姿定义为T_world_imu，属于imu0_output，不是相机光心或动捕刚体中心。世界坐标由每次OKVIS独立初始化，尚未与Motive世界坐标进行空间对齐。H5保存最终BA位姿，跟踪质量来自处理过程，不表示最终BA精度。原始输入未修改。

配置：双目虚拟针孔640×553、水平视场140°；沿用M900 profile时间偏移-0.0222秒加到IMU时间戳，image_delay=0；acc-noise=0.05，其余采用转换配置。该时间偏移不是本次实测标定，六面标定原有质量警告保留于adapter_report。Good计数、轨迹连续及最终BA完成均不代表定位精度已被验证。

中间产物：results/okvis_pose/<会话名>/export/（图像、IMU、配置、帧映射）、run/（轨迹CSV、质量CSV、日志、统计、回放）。H5的metadata含运行统计、adapter_report、配置、帧映射和时钟模型。验证H5每个位置与四元数字段与最终CSV逐值相等，时间戳严格递增、保持int64纳秒；位姿比原RGB少的帧来自转换器IMU边界覆盖筛选。

复用导出命令：
```bash
.pixi/envs/default/bin/python tools/okvis_pose_to_h5.py results/okvis_pose/<会话名>/run data/ego_pose_h5/<新文件名>.h5
```
该独立导出命令保存原始EGO时间；本次文件额外附加已有EGO时钟模型的PC时间映射。输出拒绝覆盖。
