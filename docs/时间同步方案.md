# 离线时间同步方案

目标是将 Ego 与动捕采样时刻统一到本 PC 单调时钟，再按 RGB 参考时间最近邻配对，不插值动捕标签。完整流程见 `项目数据流.md`。以下为实施建议，尚未在本项目数据上求出同步参数。

## 采集

两侧均开始录制后，录制约5–10秒不规律的左右转头、点头和停顿；结束前重复一段。动作适中，保持头戴marker可见。保留原始时间戳，不以按下录制按钮或算法处理结束的时间作为同步依据。

Ego数据：`/sensor/imu/imu0/timestamp_ns`、`gyro_rad_s`；动捕数据：时间、头戴刚体旋转、tracking_valid。若使用NatNet，核实版本是否提供曝光中点时间戳及其计时单位，不使用网络接收时间代替采集时间。

## 初步求解

Ego信号为角速度模长s_E(t)=||gyro(t)||。动捕由相邻姿态得到s_M((t_k+t_{k+1})/2)=angle(R_k^T R_{k+1})/(t_{k+1}-t_k)。不用欧拉角直接作差，排除无效跟踪和长缺口，平滑不引入未补偿的时间延迟。

对两条曲线重采样、去均值并检查幅值，再用互相关找候选偏移，细化最小化Σ[s_E(t_k)-s_M(t_k+b)]²。使用角速度模长可暂不依赖轴向外参，但重复运动可能产生多解，需检查候选峰和独立动作。

对较长录制分多个运动窗口求偏移，拟合t_M=t_M0+a·(t_E-t_E0)+b。短录制也需验证漂移是否可忽略。统一时间单位并以相对时间计算，保存原始整数时间戳。

## 图像时间的独立验证

H5虽声明相机与IMU属于同设备CLOCK_MONOTONIC，但camera_imu_offset_ns=null、temporal_calibration.status=not_calibrated。因此IMU与动捕对齐并不保证图像曝光已精确对齐。需确认图像timestamp_ns对应的采集环节。

增加带marker的可见棋盘板等独立物体，利用图像观测与动捕轨迹重投影检查并细化图像偏移。使用正确内参、畸变、旋转镜像及空间外参。不要通过最小化待评估手部算法误差来确定同步量。

## 生成配对数据

保留 Ego H5 原始时间，确定曝光参考修正后映射到 PC。此前约 −0.4 ms 是未标定估算，不代表实际误差小于 1 ms。动捕 H5 字段及写入来源待核实；手部 marker 来自 C3D，须先确认与同次动捕时间轴的帧关系。

按最新用户决定，每帧 RGB 选择 PC 采样时间最近的动捕帧，保存原始姿态和对应 C3D 样本，不插值。记录有符号时间差 dt，显式标记无效跟踪、缺口和边界。稳定 120 Hz 且无丢帧、有前后覆盖时，最近邻离散误差最多约 ±4.17 ms，其他同步误差另计。

保存 RGB/动捕原始时间、映射时间、所选帧号、C3D 索引、dt 及有效性；每段保存映射参数、原点、同步依据和残差。上文为估计时钟映射而重采样同步信号，不表示对最终标签插值。

## 精度检查

分别检查开头、中段和结尾，报告剩余时间误差及运动速度。位置误差约等于速度×时间误差：1m/s下10ms约对应10mm。插值或更密的搜索步长本身不能保证亚帧同步精度。
