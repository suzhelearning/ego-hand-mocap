# Motion 基础 Web 可视化

用户已选择 Python 本地服务＋Web 页面方案。目标是在同一三维视图查看 EGO 实体和 MOCAP Ground Truth 虚影，当前没有完整动作数据用于真实精度调试。

- 本地 Python HTTP 服务，默认仅监听 127.0.0.1；浏览器使用本地 Three.js 资源，无 CDN 运行依赖。
- 两路独立加载、显示开关、GT 透明度、旋转缩放、复位视角、统一播放/暂停/逐帧/时间轴。
- 基础对象为三维点及骨骼连接，EGO 使用不透明球体和骨段，MOCAP 使用半透明相同几何；不是完整 MANO 网格。
- 统一 motion JSON 接口：明确单位、坐标系、秒级时间戳、点坐标、骨骼连接。支持 null 缺失点和无效帧。
- 已知 NatNet H5 只作刚体位置预览；原始 Ego H5 缺少动作字段时解释原因。C3D/MANO 拟合留后续接入，不能伪造手部 GT。
- 默认使用各路相对首帧时间预览，并明确未同步；提供 MOCAP 时间偏移，不代表完成标定。已声明不同坐标系时明确告警。
- 初始为空状态，用户点击模拟示例才加载合成动作；示例始终标注。
- 方案比较：纯前端 JSON 更轻，但 H5 适配困难；选择 Python 服务便于复用现有采集生态。当前不搭建大型前端工程。
- 不做误差评分、自动对齐、MANO 拟合或同步精度承诺。
