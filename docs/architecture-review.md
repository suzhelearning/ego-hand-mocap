# 系统架构梳理与本轮优化（2026-11-01）

## 当前纵向分层

| 层 | 职责 | 主要实现 |
|---|---|---|
| 设备接入 | EGO、Windows Motive、NatNet 与时钟探针 | `joint_capture`、`natnet_zenoh` |
| 会话采集 | record 编排与会话记录；take/h5 两种模式 | `joint_capture/session.py` |
| 数据归档 | 原始回传、导入、三 H5 与处理版本 | `joint_capture/import_data.py`、`h5store.py` |
| 离线算法 | 视觉手、OKVIS、动捕 MANO/设备参考 | 第三方算法及现有离线入口 |
| 比较组装 | 依赖检查、质量筛选、固定初始化、缓存输出 | 新的 `mocap_pipeline` |
| 展示 | 单一 Z-up 场景，mocap 虚影、SLAM 与视觉手实体 | `mocap_pipeline/static`；通用查看器仍在 `motion_web` |

## 已解决的结构问题

1. **业务逻辑依赖 tools 与会话报告**：将计算、质量筛选、只读检查分到 `comparison.py`、`quality.py`、`inspection.py`。旧 tools 命令保留为兼容入口，避免两套实现。
2. **HTML 修改历史不透明**：从源码模板生成，不再对旧输出做字符串补丁；传感器坐标轴脚本也纳入源码和包资源。
3. **重复下载无用历史结果**：页面只读取当前统一比较所需缓存，删除原始视觉/动捕网格和旧设备位姿的重复加载。当前会话减少 24,367,878 字节请求载荷，约 23.24 MiB；这不是实测加载耗时。
4. **硬编码算法版本**：单一可用版本自动选择；多个或没有版本时明确报错，不静默取“最新”。支持显式选择和 `--root`。
5. **逐项碰错才发现缺失**：`pipeline status` 汇总会话清单、三 H5、SLAM/视觉处理版本、动捕参考与展示缓存依赖。检查只读，不启动硬件或安装环境。
6. **部分输出提前覆盖**：帧数、时间轴、二进制大小验证后，先在临时目录准备全部产物，再逐文件原子替换。单个文件不会半写；整个文件集合不是事务，导出时应停止播放、完成后刷新页面。
7. **坐标辅助层可复现性不足**：展示模板和传感器轴代码具有独立指纹；输入数组、计算代码及质量门槛继续记录。

## 统一入口

```bash
./mocap record
./mocap pipeline status --session 20261030_182714_db5456
./mocap pipeline status --session 20261030_182714_db5456 --json
./mocap pipeline export --session 20261030_182714_db5456
# 多版本时显式选择
./mocap pipeline export --session 20261030_182714_db5456 \
  --slam-run okvis-20261101 --vision-run sch-v21-temporal-v1
```

`status` 就绪返回 0、依赖不足返回 1；ready 只是依赖存在，不等于输入数值、标定或精度认证通过，export 继续执行数值检查。

## 本轮保留的边界与后续项

- 尚未把所有第三方推理过程合并成一个自动执行 DAG；本轮统一的是状态检查与比较导出。
- 参考 Web 缓存仍来自已有离线流程，`slam.json` 中的候选安装外参与时间偏移仍是历史依赖。已明确检查该依赖，未将其冒充独立标定。
- 动捕参考目前仍按帧索引/采样率构造时间，需要后续以原始时间戳与帧连续性校验替代。
- 正式统一导出应最终由三 H5 直接重建全部参考缓存，减少对 reports 的依赖；需要同时明确参考手部与 marker 模板的数据契约。
- `joint_capture/runs.py` 仍包含历史多目录运行结构；贸然迁移会影响旧回放及配对导出，本轮不改已有数据。
- IMU/marker 物理外参、时钟关系以及手部语义仍待确认；本轮不产生独立精度结论。

## 后续实施更新：三 H5 与统一执行器

上文剩余项中的“参考缓存依赖 reports”和“未统一算法编排”现已实现：新增 reference、adapters、runner 模块，参考资源从三个 H5 重建，四阶段通过内容指纹和会话锁串联；实现与适配范围见 [pipeline 运行器](pipeline-runner.md)。仍保留候选标定和历史刚体参考版本，尚不支持任意新设备或 marker 标签的自动适配。
