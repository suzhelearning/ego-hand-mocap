### 时间同步方案（2026-10-28历史草案，已废弃）

**目标**：实现 **Ego 相机与动捕相机**的时间同步——两端使用同一时间基准，偏移可测、误差可控。外骨骼上的录制事件是当前可用的对齐信号来源。

**当前可用信号**

1. Ego 录制由机身右侧按钮触发，无程序控制接口
2. 按钮触发后，录制开始事件会同步传到外骨骼（可作为 Ego 与动捕之间的共享事件源）
3. 有线：USB 连接 Ego 后可监听相机 IP；无线：连接相机 WiFi 后可监听

**草案流程**

1. 以「录制按钮按下」作为统一触发事件 T0
2. 采集端通过 USB / 相机 WiFi 监听 Ego，记录录制开始时间戳
3. 从外骨骼日志提取同一次按钮事件的时间戳
4. 计算两端差值，作为固定偏移做对齐；后续每次录制重复校准
5. 如漂移明显，再引入 NTP/PTP 或外部硬件触发

**待确认事项**

- 按钮事件到 Ego、外骨骼两侧的实际延迟及抖动
- 外骨骼侧时间字段的名称、单位、精度
- 相机与采集主机时钟是否同源，是否需要定期重新校准
- 坐标系统一：头戴设备以左侧 RGB 相机光心为原点，参考系 `cam0_optical`，右手系
