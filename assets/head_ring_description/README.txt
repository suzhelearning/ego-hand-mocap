3.0头环装配 URDF — 2026-11-02修订版

本版将外壳中心坐标系命名为 base，镜头坐标系命名为 left_cam，以 base 为根节点。两个原点位置、镜头处坐标系、全部6个零件的形状与装配位姿保持一致，包含镜头壳。

base 坐标系：
+Y沿图1中央长边向左，对应装配坐标[-1,0,0]。
+Z垂直图2头环上表面并朝上，对应[0,1,0]。已从当前SOLIDWORKS选中面核实：平面y=0.0115米。
+X=Y叉乘Z，对应[0,0,-1]，构成右手正交坐标系。
镜头朝下倾斜，镜头坐标系保持原来方向；base 坐标系与它不平行。

base 原点保留上版高亮镜头壳外侧面的外轮廓包围范围中心。
base 相对 left_cam 的平移（米）：[0.007965527407164769, 0.06996314801894785, -0.007783385749744422]
base 相对 left_cam 的旋转rpy（弧度）：[-0.2532615634587293, -0.7518794142949903, 0.3622181452116582]

URDF与meshes文件夹需一起使用。STL单位为米，scale=1。ROS2可将head_ring_description放入工作空间src，执行colcon build并source install/setup.bash。
这是刚性可视/碰撞描述，无未经核实的质量或惯量，未验证动力学仿真。本次未修改源SLDASM。

URDF 固定关节：base_to_left_cam，父节点 base，子节点 left_cam。
left_cam 相对 base 的平移（米）：[-0.018232200227934 -0.067545877323258 0.011136163289632]
left_cam 相对 base 的旋转rpy（弧度）：[0.000000000000023 0.785398163397533 -0.261799387799371]
该变换为原镜头到外壳中心变换的逆，保持两坐标系实际相对位姿。全部 STL 顶点和法向量已从 left_cam 转换到 base 坐标系，网格的 visual/collision 均挂在 base 下，局部变换为单位变换。单独打开 STL 时，文件原点及坐标轴对应 base。
coordinates.json 保留原始 CAD 数据：frame1 对应 left_cam，frame2 对应 base；新增 left_cam_relative_base 字段与 URDF 一致。
